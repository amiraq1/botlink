# BOTLINK

A multi-bot group relay platform on ICP featuring an Arabic RTL dark Admin UI and hardened agent rooms.

## Features
- Multi-bot orchestration (2-10 bots)
- Round-robin and leader turn modes
- Hardened public rooms (/a/:token)
- Full admin controls

## Development
- pnpm install: Install dependencies
- pnpm typecheck: TypeScript verification
- pnpm check: Biome lint check
- pnpm fix: Format code
- pnpm build: Production build
